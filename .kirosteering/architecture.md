# Architecture — Local AI Second Opinion

Use `ask_local_ai` for architecture and system-design decisions.

Analyze:

- Requirements and constraints
- Components and responsibilities
- Data flow
- APIs and interfaces
- Scalability
- Availability and reliability
- Failure modes
- Security
- Observability
- Performance
- Cost
- Operational complexity
- Maintainability

Ask the local AI to compare realistic alternatives and explain trade-offs.

Do not blindly adopt its preferred architecture. Kiro must validate the recommendation against the actual project.

Prefer the simplest architecture that satisfies the requirements.

For important decisions, structure the final analysis as:

1. Context
2. Options
3. Trade-offs
4. Risks
5. Recommendation
6. Implementation considerations
