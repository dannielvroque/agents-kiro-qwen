# Git — Local AI Second Opinion

Use `ask_local_ai` for Git workflows and repository problems.

Consider:

- Branching
- Merge
- Rebase
- Cherry-pick
- Conflicts
- Reflog
- Reset
- Revert
- Tags
- Remote tracking
- Commit history
- Release workflows
- Conventional commits
- CI integration

Prefer safe operations.

Clearly distinguish:

- Working tree changes
- Staged changes
- Local commits
- Remote commits

Never recommend force push or destructive history rewriting without explicitly explaining the consequences.

When recovering lost work, inspect reflog and repository state before changing anything.
