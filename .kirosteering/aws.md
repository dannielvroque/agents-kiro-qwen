# AWS — Local AI Second Opinion

Use `ask_local_ai` for AWS architecture, troubleshooting and implementation analysis.

Consider:

- IAM and least privilege
- VPC, subnets, routing and security groups
- EC2
- ECS/EKS
- Lambda
- API Gateway
- S3
- CloudFront
- Route 53
- SQS/SNS
- DynamoDB
- RDS
- Secrets Manager
- CloudWatch
- Autoscaling
- High availability
- Disaster recovery
- Cost
- Security
- Observability

For AWS problems, provide the local AI with the relevant region, resource type, architecture, error messages and configuration.

Do not invent AWS features or CLI arguments.

For current AWS behavior, limits, pricing or service features, Kiro must verify official AWS documentation when necessary.

Never apply destructive infrastructure changes without explicit user intent and appropriate validation.
