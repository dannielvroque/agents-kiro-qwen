# Kubernetes — Local AI Second Opinion

Use `ask_local_ai` for Kubernetes and EKS tasks.

Analyze:

- Pods
- Deployments
- StatefulSets
- DaemonSets
- Services
- Ingress
- ConfigMaps
- Secrets
- Namespaces
- RBAC
- ServiceAccounts
- Probes
- Requests and limits
- HPA
- Scheduling
- Storage
- Networking
- DNS
- Security
- Observability
- Helm
- EKS architecture

For incidents, ask for hypotheses supported by evidence from:

- kubectl output
- Events
- Logs
- Resource status
- Metrics
- Manifests

Do not assume that a pod restart is the correct solution.

Never delete production resources without explicit intent and validation.
